# FC-Portfolio

The Frontier Commons Portfolio for 2026: the tools built across the Spring, Summer and Fall cohorts.

- `index.html` — the portfolio page (tabs: Spring, Summer, Fall, All; link to a tab with `#fall` etc.)
- `assets/` — the logo and the demo videos the Fall projects play

Open `index.html` in a browser, or view it on GitHub Pages.

Frontier Commons is a ministry of IFI. More tools at [frontiercommons.org/tools](https://frontiercommons.org/tools/).
